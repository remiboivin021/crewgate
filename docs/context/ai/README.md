# AI Context

This directory contains context about the AI system (OpenCode) used to develop the AI GTM OS project.

## Files

- **agent_context.md**: Agent architecture, skills, tools, behavior rules
- **model_context.md**: Model provider, capabilities, constraints, configuration
- **prompt_context.md**: Prompt architecture, conventions, templates, anti-patterns
- **safety_context.md**: Content policy, trust boundaries, data privacy, incident response

## Purpose

These files help the AI agent (OpenCode) understand:
- How it should behave (agent_context.md)
- What model/capabilities it has (model_context.md)
- How prompts are structured (prompt_context.md)
- What safety constraints apply (safety_context.md)

## Maintenance

Update these files when:
- New skills are added to `.opencode/skills/`
- Model configuration changes
- Safety requirements evolve
- New AI capabilities are integrated
